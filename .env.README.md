# Environment Variables Guide

## 📁 File Structure

```
.
├── .env                # ✅ Safe defaults (COMMIT THIS)
├── .env.local          # 🔒 Your secrets (DO NOT COMMIT)
├── .env.example        # 📋 Template (COMMIT THIS)
└── server/
    ├── .env            # 🔒 Server secrets (DO NOT COMMIT)
    └── .env.example    # 📋 Server template (COMMIT THIS)
```

## 🚀 Quick Start

### For New Developers:

1. **Copy the example file:**
   ```bash
   cp .env.example .env.local
   ```

2. **Fill in your API keys in `.env.local`:**
   - Get WalletConnect ID: https://cloud.walletconnect.com
   - Get Alchemy keys: https://www.alchemy.com
   - Get CoinGecko key: https://www.coingecko.com/en/api
   - Get 0x key: https://0x.org/docs
   - Get Supabase keys: https://supabase.com

3. **Start development:**
   ```bash
   npm run dev
   ```

## 📊 Vite Environment Priority

Vite loads `.env` files in this order (higher = higher priority):

1. `.env.[mode].local` (highest - e.g., .env.production.local)
2. `.env.local` ⬅️ **Your secrets go here!**
3. `.env.[mode]` (e.g., .env.production)
4. `.env` (lowest - safe defaults)

## 🔒 Security Best Practices

### ✅ DO:
- Keep secrets in `.env.local`
- Commit `.env` with safe defaults
- Commit `.env.example` as a template
- Use environment-specific files for production

### ❌ DON'T:
- Commit `.env.local` to git
- Put API keys in `.env`
- Share secrets in chat/email
- Use production keys in development

## 🔧 Configuration Details

### Frontend (.env)
- `VITE_API_URL`: Backend API endpoint (port 8787)
- `VITE_WALLETCONNECT_PROJECT_ID`: Web3Modal connection
- `VITE_ALCHEMY_*_URL`: RPC providers for each chain
- `VITE_COINGECKO_API_KEY`: Price data API
- `VITE_ZEROX_API_KEY`: 0x protocol for swaps
- `VITE_SUPABASE_*`: Database connection

### Backend (server/.env)
- `PORT`: Server port (8787)
- `ORIGIN`: CORS origin (Vite dev server)
- `COINGECKO_API_KEY`: Price API key
- `RATE_LIMIT_*`: API rate limiting config

## 🐛 Troubleshooting

### "API connection failed"
- Check `VITE_API_URL` matches server `PORT` (both should be 8787)
- Ensure server is running: `npm run api:dev`

### "WalletConnect not working"
- Verify `VITE_WALLETCONNECT_PROJECT_ID` in `.env.local`
- Check project is active at https://cloud.walletconnect.com

### "Missing environment variable"
- Copy `.env.example` to `.env.local`
- Fill in all required API keys
- Restart dev server: `npm run dev`

## 📝 Environment Modes

### Development (default)
```bash
npm run dev
# Loads: .env.local + .env.development + .env
```

### Production Build
```bash
npm run build
# Loads: .env.production.local + .env.production + .env
```

### Preview
```bash
npm run preview
# Serves production build locally
```

## 🔐 Vercel Deployment

Add these environment variables in Vercel dashboard:
- All `VITE_*` variables from `.env.local`
- Set `VITE_API_URL` to your production backend URL

Never commit `.env.local` - add secrets via Vercel UI!
