# Contracts, generated artifacts, and execution scripts

- Edit Solidity in `contracts/src/`. Synchronize only the mirror pairs listed
  in `scripts/verify-contract-sources.mjs`; run `npm run contracts:verify`.
  Solidity files under `documentation/` are not canonical sources.
- Foundry configuration in `contracts/foundry.toml` pins solc 0.8.28. The
  separate Node compilation script uses a different compiler; do not silently
  substitute its output for Foundry artifacts or deployed-source evidence.
- Compile before regenerating affected artifacts. `npm run abi:sync` handles
  the contracts listed in `scripts/sync-abis.ts`.
  `node scripts/generate-launchpad-artifacts.mjs` regenerates launchpad ABIs
  and bytecode from compiled output. `npm run dex:artifacts` regenerates
  pinned Uniswap V2 artifacts and checks their pair init-code hash.
  Do not hand-edit generated bytecode or ABI arrays.
- Run `npm run contracts:check`; a targeted example is
  `npm run contracts:test -- --match-contract GovernanceTokenTest`.
  `OwnDex.t.sol` and `YieldVaultBaseFork.t.sol` need a Base RPC; the latter
  needs historical state. `AmmFork.t.sol` returns early without
  `AMM_FORK_RPC_URL`, so a pass alone does not prove fork assertions ran.
- Review `SECURITY.md` and relevant `audit/` records for fund-handling changes.
  Record source/deployment differences accurately; editing source does not
  update deployed contracts or justify replacing deployment addresses.
- Inspect scripts before running them. Some deploy, seed liquidity, or trade.
  Use simulation or explicit dry-run modes for development, and honor the
  session's authorization scope for signing, broadcasting, and live execution.
