1. EXECUTIVE SUMMARY & RATIONALE
================================================================================

Currently, all deployment, liquidity seeding, staking configuration, and swap
testing functions were placed onto a single card on http://localhost:5173/launchpad.

While this allowed for fast bootstrapping of the initial contracts (Steps #1, #2,
#3, and #4), it creates UI clutter and mixes creator deployment tools with
day-to-day trader and administrator interfaces.

Separating these functions into dedicated, specialized pages follows Web3
production standards (like Uniswap, Aerodrome, and PancakeSwap), delivering an
intuitive, scalable user experience.

================================================================================
2. DEDICATED PAGES ARCHITECTURE
================================================================================

1. Launchpad Studio (/launchpad):
   - Audience: Token Creators
   - Function: Pure Creator Studio. Clean 4-step wizard (Identity, Architecture,
     Liquidity, Review) to deploy brand-new tokens, vaults, and governance protocols.

2. Protocol Ops Hub (/protocol):
   - Audience: Protocol Admin / Owner
   - Function: Ecosystem Management Console. Real-time contract registry for
     deployed suites (AMUTT, Aave Vault, Staking, Borrower), 1-click MetaMask
     token importer, and VIP staking tier controls.

3. DEX Trading Swap (/swap):
   - Audience: Public Traders & Community
   - Function: Decentralized Exchange. Clean candlestick charts, order routing
     via Base Uniswap V2 Router, slippage protection, and instant token swaps
     (ETH <-> AMUTT <-> SD).

4. Liquidity Manager (/liquidity):
   - Audience: Liquidity Providers
   - Function: Pool Management. Initialize new pairs, add/remove pool liquidity,
     view LP tokens (158.11 LP tokens), and monitor pool fees.

5. Staking & Loyalty (/stake):
   - Audience: Token Holders & VIPs
   - Function: Single-Sided Staking. Stake AMUTT to unlock 5%-30% fee discount
     tiers and view real-time reward accumulations.
